# User Manual

## Overview

BookMyQ is designed for customer-facing service environments that need queue management, appointment scheduling, and operational visibility.

## Common user actions

### Customer
- Search for a branch and service
- Book an appointment or join a walk-in queue
- View real-time queue status and notifications
- Submit feedback after service

### Staff
- Sign in to branch dashboard
- Call next token and update service status
- Transfer or reassign queue items
- Review SLA and branch performance

### Manager
- Oversee queue health and staffing loads
- Review analytics, wait times, and no-show trends
- Configure holiday and capacity policies

## Support and troubleshooting

- Check notification delivery logs when customers fail to receive updates
- Verify branch schedule and holiday mapping when appointment capacity is missing
- Review token status and service assignment when delays occur
