# User Stories

## Super Admin

- As a super admin, I want to create and manage tenants so that the platform can serve multiple businesses.
- As a super admin, I want to configure subscription plans so that each tenant is billed appropriately.

## Platform Admin

- As a platform admin, I want to control tenant onboarding so that new customers can be activated securely.
- As a platform admin, I want to monitor global health and usage so that the platform remains stable.

## Tenant Owner

- As a tenant owner, I want to customize branding and services so that the customer experience matches my business.
- As a tenant owner, I want to set branch hours and queue rules so that operations are predictable.

## Branch Manager

- As a branch manager, I want to view real-time branch queues so that I can allocate agents effectively.
- As a branch manager, I want to manage staffing and resources so that service targets are met.

## Receptionist

- As a receptionist, I want to register walk-ins and issue tokens so that queues can move smoothly.
- As a receptionist, I want to manage waitlists so that customers are accommodated without friction.

## Agent

- As an agent, I want to update customer status in real time so that queue progress is accurate.
- As an agent, I want to view service history so that service continuity is maintained.

## Customer

- As a customer, I want to book an appointment so that I can avoid long waits.
- As a customer, I want to track my queue position so that I know when to approach the service desk.

## Support Team

- As a support team member, I want to access customer records and notifications so that I can resolve issues quickly.
- As a support team member, I want to review SLA events so that service quality can be improved.
