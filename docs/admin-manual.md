# Admin Manual

## Platform administration

- Manage tenants, subscriptions, and users
- Configure branding, domain mapping, and onboarding forms
- Manage global policies such as SSO, MFA, and security settings

## Tenant administration

- Create and maintain branches
- Define service catalog and resource allocation
- Set working hours, calendar availability, and queue rules
- Review billing and invoice status

## Operations administration

- Monitor queue dashboard and real-time service KPIs
- Manage CRM sync, notifications, and integrations
- Review audit logs and compliance events

## Security and compliance

- Enforce role-based access control
- Audit admin events and customer access records
- Monitor data retention and consent actions for GDPR readiness
