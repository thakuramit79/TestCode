# UI Wireframes

## 1. Customer portal: appointment booking

- Header with tenant branding and location selector
- Service category cards
- Branch card list and calendar slot picker
- Booking summary sidebar
- CTA: Book Appointment

## 2. Queue dashboard

- Queue overview with service counters
- Live tokens table with status and ETA
- Action controls: call next, transfer, pause, complete
- Resource utilization panel
- AI recommendation insights panel

## 3. Admin dashboard

- KPI cards for queue load, SLA, conversion, and wait time
- Branch performance charts
- Recent notifications and alerts
- Tenant-level summary table

## 4. Agent mobile app

- Current queue card
- Token status buttons
- Notification center
- Quick feedback and service completion actions

## 5. Admin onboarding flow

- Tenant signup form
- Business profile details
- Branch creation flow
- Service catalog setup
- Billing and subscription setup
